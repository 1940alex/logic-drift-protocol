# Logic Drift Paper Demo

This folder is the lean paper-first package for the Logic Drift preprint. It is not intended to be a product app. It is a reproducibility/demo bundle: manuscript source, protocol prompts, data, analysis script, processed tables, and figures.

## Current Contents

- `paper/source/logic_drift_v18_source.md` - canonical source manuscript copied from `C:\Users\atsak\Downloads\0412logic drift paper v18 .md`.
- `prompts/logic_drift_protocol_v24.md` - protocol prompt used by the original dataset.
- `data/raw/ldp_complete_dataset_100_runs_7llms.csv` - cleaned analysis dataset found in Downloads.
- `scripts/analyze_logic_drift.py` - dependency-free analysis script.
- `data/processed/model_summary.csv` - per-model summary generated by the script.
- `data/processed/overall_summary.csv` - overall summary generated by the script.
- `figures/*.svg` - simple paper/demo figures generated by the script.
- `handoff/` - readiness audit, related-work notes, and contractor brief.

## Reproduce The Tables And Figures

From the project root:

```powershell
python .\scripts\analyze_logic_drift.py
```

The script uses only the Python standard library.

## Current Reproduced Results

The cleaned dataset contains 697 successful runs across 7 models. The generated overall summary reports:

- Mean consensus score: 82.63
- Mean inductive logic score: 59.67
- Mean deductive validity score: 10.33
- Mean LDS: 72.29
- Mean neutral-domain score: 45.35
- Mean Semantic Delta: 14.30

These values are close to the v18 manuscript highlights and should replace any less precise prose claims during the paper rewrite.

## Security Note

Old harness config files in Downloads contained a hard-coded OpenRouter API key. Those files were not copied into this package. `config.example.json` uses the `OPENROUTER_API_KEY` environment variable instead.

## Paper-First Scope

The near-term deliverable is an arXiv/OSF-ready preprint with a minimal reproducibility artifact. Future FOI benchmark ideas, dossier engines, gaslighting probes, and richer app interfaces should remain out of this first paper unless new data is collected specifically for them.
